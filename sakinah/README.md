# Sakinah | সাকীনা

A lightweight, responsive Bengali-first Quranic dua finder. The static MVP matches a user's described feeling to a curated set of Quranic supplications using local keyword matching. It includes Arabic text, Bengali transliteration and meaning, verse references, copy/share actions, and browser-local bookmarks.

## Run locally

Open `index.html` in a modern browser. No build step, server, paid API, or account is required.

## Deployment

This folder can be served as a static subdirectory from the repository's existing website. If GitHub Pages is enabled for the repository, visit the site's `/sakinah/` path after the commit is published.

## Content and privacy

- User text is processed in the browser and is not sent to a server.
- Bookmarks are stored in browser local storage on this device.
- Matching is keyword-based, not an AI or clinical assessment.
- Verse references link to Quran.com for further review. Bengali pronunciation and meanings are provided as aids; translations may vary.
- This MVP does not yet include a backend or admin dashboard.
